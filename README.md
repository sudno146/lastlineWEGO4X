# lastlineWEGO4X

turnBasedStrategy con elementos wego / 4x 

los jugadores planean sus acciones simultáneamente y, cuando terminan sus turnos, el juego calcula y resuelve todo.

el mapa está basado en una cuadrícula y cuenta con 3 planos:

underground
surface
air

cada plano tiene sus propias características, recursos y posibilidades.

el combate utiliza cosas como hp, dpt, rango, velocidad e iniciativa, además de diferentes patrones de ataque.

también habrá:

fog of war
recursos y estructuras
producción de unidades
modificación del terreno
sistema modular de unidades
árboles de habilidades
turnos con tiempo límite
multiplayer / ia

la idea principal es:

planear → ejecutar → resolver → adaptarse.

proyecto actualmente en desarrollo.
